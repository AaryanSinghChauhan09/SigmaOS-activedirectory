# SigmaOS Active Directory

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-activedirectory`.

No directory client, LDAP/Active Directory authentication, policy integration, or networking behavior is implemented in the current source.

## Build

```sh
cargo check --lib
```
